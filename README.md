<h1>Snippets</h1>

<p>Save the commands you run often and run them in a terminal or on many hosts in one click</p>

</div>

<br />

## Overview

Snippets keeps the commands and text you use often in one place, ready to run in a terminal.

<br />

## Install

Snippets ships with [Termix](https://github.com/Termix-SSH/Termix). Admins can turn it on or off, update it or install it again from the Plugins tab. Want to see it first? Try the [demo](https://demo.termix.site/), any username and password works.

<br />

## Features

- Save commands and notes in folders
- Run them in one or more terminals, or straight on a set of hosts
- Variables for the host and your own inputs
- Run a snippet each time you connect to a host
- Share snippets with users or roles
- Import and export as JSON

<br />

## Services

Provides to other plugins:

- `snippets.access`: read and run snippets
