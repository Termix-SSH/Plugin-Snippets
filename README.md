## Overview

Snippets keeps the commands and text you use often in one place, ready to run in a terminal.

<br />

## Features

- Save commands and notes in folders
- Run them in one or more terminals, or straight on a set of hosts
- Variables for the host and your own inputs
- Run a snippet each time you connect to a host
- Share snippets with users or roles
- Import and export as JSON

## Support

Found a bug or have an idea for Snippets? Open an issue in this repo: [report a bug](https://github.com/Termix-SSH/Plugin-Snippets/issues/new?template=bug_report.yml) or [request a feature](https://github.com/Termix-SSH/Plugin-Snippets/issues/new?template=feature_request.yml). The quickest way to report a bug is **Report an issue** on this plugin's page in the Termix Plugins tab, which fills in your versions for you.

Problems with Termix itself (login, hosts, credentials, sharing, sync) go in the [Termix repo](https://github.com/Termix-SSH/Termix/issues/new/choose). Not sure where it goes? Open it there and it will be moved.

Please be as detailed as possible, preferably in English. For questions, join the [Discord](https://discord.gg/jVQGdvHDrf) server.
